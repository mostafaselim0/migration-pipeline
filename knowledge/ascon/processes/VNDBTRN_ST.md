# VNDBTRN_ST - حركات موردين مدينة - انظمة أخرى / Debit Transactions from Other Systems

- Registry: system 5 serial 5 (menu `FILES_MENU.ITEM161`, order 102). APEX list page 40020, document page 40021.
- **Deliverable: screen correction + rules** - `app\legacy\overrides\VNDBTRN_ST.json` (`MASTER_DETAIL`, insert/delete off, update on);
  validation `APP_RULES_VN.check_st` (`app\db\21_rules_vn.sql`).
- Purpose: view the supplier debit transactions generated by other systems (POST_SYSTEM set: purchase returns 205 posted from purchasing,
  LINK_FLAG 1, POST_FLAG 1) with their invoice allocations; adjust descriptive data only.
- **Confidence: medium** - compiled form only; WHERE and the absence of insert/numbering SQL are clear, the editable set is inferred.
